# LDC_ComLabLink

A web-based computer laboratory seat reservation system developed for Liceo de Cabuyao as a group academic project. It helps manage laboratory seat reservations and user accounts.

## Features
- Create and update user accounts
- Reserve computer laboratory seats
- Manage user reservations
- Deactivate user accounts

## Technologies Used
- React.js
- Vite
- Express.js
- Firebase
- Firestore
